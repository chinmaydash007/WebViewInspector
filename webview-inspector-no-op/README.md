# Production no-op

Publishes `io.github.chinmaydash007:webview-inspector-no-op` with the same five facade methods and package as the full artifact. Installation, settings and mutations do nothing; `isEnabled()` returns false. No inspector UI, observers, URL access, Material or WebKit dependency is included.

Choose exactly one artifact per variant. See [integration](../README.md), [architecture](../webview-inspector/docs/ARCHITECTURE.md) and [validation](../VALIDATION.md).
